# Taller Práctico: Asincronía en JavaScript

## Objetivo

Aplicar los conceptos de Promesas, Callbacks y Async/Await en JavaScript para resolver flujos de trabajo asíncronos y no bloqueantes.

## Ejercicios

1. Simulador de Retiro de Cajero Automático (ATM)
2. Verificación de Edad para Suscripción
3. Consulta de Clima Local

## Tecnologías utilizadas

- JavaScript
- Node.js
- Visual Studio Code
- Git
- GitHub
