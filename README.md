# Taller Práctico: Asincronía en JavaScript

## Objetivo

Aplicar los conceptos de Promesas, Callbacks y Async/Await en JavaScript para resolver flujos de trabajo asíncronos y no bloqueantes.

## Ejercicios desarrollados

### Ejercicio 1 - Simulador de Retiro ATM

Implementación de una operación asíncrona utilizando:

- Promise
- resolve
- reject
- setTimeout
- then
- catch

Se prueban dos escenarios:

- Retiro exitoso de $200.
- Retiro rechazado de $600.

### Ejercicio 2 - Verificación de Edad

Simula la validación de edad para el registro de un usuario.

Utiliza:

- Promise
- resolve
- reject
- setTimeout
- then
- catch

### Ejercicio 3 - Consulta de Clima Local

Simula una consulta asíncrona del clima.

Utiliza:

- Promise
- async
- await
- try-catch
- setTimeout

## Tecnologías utilizadas

- JavaScript
- Node.js
- Visual Studio Code
- Git
- GitHub

Ejercicio 1:

```bash
node ejercicios/ejercicio1-atm.js
```

Ejercicio 2:

```bash
node ejercicios/ejercicio2-edad.js

```

Ejercicio 3:

```bash
node ejercicios/ejercicio3-clima.js`
```
